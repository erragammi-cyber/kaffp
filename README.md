# Приложение "Будь первым!"

Приложение для создания персонализированных тренировок на основе физических параметров пользователя.

## Описание

Приложение позволяет пользователям:
- Вводить свои физические параметры (подтягивания, бег на 100м, 5км и т.д.)
- Выбирать дни тренировок
- Получать персонализированные тренировки на основе уровня подготовки
- Отмечать выполненные тренировки
- Просматривать детали каждой тренировки

## Особенности

1. **Адаптивные тренировки** - приложение анализирует уровень подготовки пользователя и предлагает тренировки, соответствующие его уровню
2. **Персонализация** - если пользователь слаб в каком-то аспекте (например, бег или подтягивания), ему будут предложены тренировки для улучшения именно этих качеств
3. **База тренировок** - 30 различных тренировок с различными уровнями сложности и направленностью
4. **Отслеживание прогресса** - возможность отмечать выполненные тренировки
5. **Детализация** - подробное описание каждой тренировки с разминкой, основной частью и заминкой

## Структура проекта

- `main.py` - основной файл приложения
- `trainings.json` - база данных тренировок
- `test_app.py` - файл для тестирования логики приложения

```bash
pip install tkcalendar
```

## Запуск приложения

```bash
python3 main.py
```

## Функциональность

1. **Вкладка "Настройки"**:
   - Выбор курса обучения
   - Ввод параметров по нормативам (сила, выносливость, быстрота)
   - Выбор дней тренировок в календаре

2. **Вкладка "Предстоящие тренировки"**:
   - Просмотр сгенерированных тренировок
   - Отображение статуса выполнения (выполнено/не выполнено)
   - Кнопка "Подробнее" для просмотра деталей тренировки
   - Кнопка "Выполнено" в окне деталей тренировки

3. **Алгоритм генерации тренировок**:
   - Анализ уровня подготовки по трем направлениям: сила, выносливость, быстрота
   - Определение приоритетов на основе слабых мест
   - Подбор тренировок соответствующего уровня сложности
   - Балансировка нагрузки в течение недели

## Структура тренировки в JSON

Каждая тренировка в базе данных имеет следующую структуру:

```json
{
  "id": "S-1",
  "name": "Базовая силовая",
  "type": ["сила"],
  "level": "базовый",
  "duration_min": 60,
  "warmup": "Бег 5 мин, приседания без веса — 2×15, круговые вращения плечами",
  "main": [
    { "exercise": "Приседания со штангой", "sets": 3, "reps": 6, "rest_sec": 150 }
  ],
  "cooldown": "Растяжка спины, груди, бёдер",
  "tags": ["сила", "база", "снаряды"]
}
```

## Логика работы

Приложение оценивает уровень подготовки пользователя по трем направлениям:
- **Сила** - на основе результатов в подтягиваниях и подъеме переворотом
- **Выносливость** - на основе результатов в беге на 3км, 5км и марш-броске
- **Быстрота** - на основе результатов в беге на 100м, 60м и челночном беге

На основе этих данных определяются приоритеты тренировок:
- Если уровень "Fail" или "Satisfactory" - высокий приоритет на развитие этого качества
- Если уровень "Good" - средний приоритет
- Если уровень "Excellent" - низкий приоритет

Приложение автоматически подбирает тренировки, соответствующие приоритетам и уровню подготовки пользователя.
